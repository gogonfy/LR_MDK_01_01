# Лабораторная работа №3. Цветочный магазин

Консольная программа на C# для оформления заказа в цветочном магазине.

## Задание

Программа должна:

- выводить ассортимент цветов с номерами позиций, ценами и остатками;
- в цикле запрашивать номер цветка и количество;
- завершать ввод при вводе номера `0`;
- проверять, хватает ли каждого цветка с учётом суммарного количества по всем позициям;
- при успешной проверке списывать остатки и выводить стоимость заказа;
- при нехватке сообщать, какого цветка не хватает, и не менять остатки;
- в конце выводить остатки по каждому цветку.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `LR3/ProductType.cs` | перечисление `ProductType` — виды цветов |
| `LR3/Product.cs` | класс `Product` — товар: название, цена, количество |
| `LR3/FlowerShop.cs` | класс `FlowerShop` — ассортимент, корзина, проверка и обработка заказа |
| `LR3/Program.cs` | точка входа, запуск сценария |

## Ассортимент

| № | Цветок | Цена | Остаток |
|---|--------|------|---------|
| 1 | роза | 180 руб. | 24 шт. |
| 2 | тюльпан | 120 руб. | 30 шт. |
| 3 | хризантема | 350 руб. | 14 шт. |
| 4 | орхидея | 1200 руб. | 6 шт. |
| 5 | гипсофила | 90 руб. | 40 шт. |

## Запуск

1. Открыть `LR3.slnx` в Visual Studio.
2. Нажать `F5`.

Либо собрать из консоли:

```powershell
msbuild LR3.slnx /p:Configuration=Debug
.\LR3\bin\Debug\LR3.exe
```
